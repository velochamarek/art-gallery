# ArtGallery

Interaktivní webová galerie, kde uživatelé mohou prohlížet obrazy a zároveň do nich malovat.

## Funkce

- Prohlížení obrazů v galerii  
- Kreslení přímo do obrazu  
- Ukládání úprav do lokální paměti
- Možnost stažení upraveného obrazu  
- Historie obrazů uložená v prohlížeči  
- Podpora češtiny a angličtiny  

## Ukázka

https://artgallery-12b.pages.dev/

## Technologie

- HTML  
- CSS  
- JavaScript  

## O projektu

Projekt vznikl během hackathonu jako rychlý prototyp kombinující online galerii s možností interaktivní tvorby přímo v prohlížeči.
